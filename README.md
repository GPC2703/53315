## ¿De que se trata este proyecto?  
Mi proyecto se tratara sobre un analizador que debera realizar las siguientes tareas:  
1- Analisis lexico y sintactico  
2- Tabla de Lexemas-Tokens  
3- Arbol de analisis sintactico  
4- Interpretacion  

## Instalacion
1- Vamos a clonar este repositorio
```bash
   git clone https://github.com/GPC2703/53315  
   ```
(Si el proyecto se clonó bien deberiamos ver “done” en la salida)  
2- Ahora instalaremos y verificaremos las dependencias que tiene el Node.js ingresando a la carpeta del proyecto  
 ```bash
   cd ProyectoAnalizador  
   npm install  
 ```

## Cómo ejecutar el programa
Debemos ingresar a la carpeta "53315" y luego al directorio/carpeta "ProyectoAnalizador" antes de ejecutar el programa.   
Podemos iniciar el analizador con Node.js ejecutando lo siguiente en la consola:  
```bash
  cd ProyectoAnalizador  
  node index.js  
```

Extra: El programa utilizara con codigo fuente el archivo llamado 'input.txt', en este podras modificar la entrada a tu gusto.
